# ProjectItem

A project link with an arrow-out icon and a one-line description underneath.

- The name is DM Sans 600 at 16px, an inline-flex link with the 16px arrow-out icon at 60% opacity, 4px after it.
- The description is 14px/1.6 `text-dim`, 6px below. Write one sentence that says what it is and what it was built with.
- Items stack in a single list, with no thumbnails.
- The consumer supplies the URL, its own i18n keys for the EN/DE name and description (never reuse another project's keys).
