# GroupLabel

A small sentence-case label above a group of items, currently used only above the certification list ("Pega Certifications").

- 12px Inter in `text-dim`, with `space-14` below. Sentence case, no tracking.
- Sections themselves have no visible headings. Only add a GroupLabel where a section holds a named set (like a vendor's certifications).
- The consumer supplies the text in both languages ("Pega-Zertifikate").
