# PillButton

A 38px round control for global toggles (language, theme) that holds a short lowercase label or a 16px icon.

- Fill is `pill`, hover is `pill-hover` with a 1px lift (`.2s`). The label or icon is in `text`.
- Theme toggle: show the sun in dark mode and the moon in light mode (the icon shows what you switch to).
- Language toggle: show the current language code, `en` or `de`.
- Always give it an `aria-label`. Stack toggles `space-10` apart.
